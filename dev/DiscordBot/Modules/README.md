**Run your own Discord Bot from CommandHelper!**

**This bot is still in active development so internal features may change or break at any time!**

These are optional Bot components. Only include them with your Bot installation if you require use of the various functions given.  


## Modules:  
- IP Reactions:  
    - By reacting with a configured emoji to [IP Blacklist's](https://github.com/cypher139/ch/tree/release/dev/IPBlacklist) IP ping messages, the IP is added to IP Blacklist file.
